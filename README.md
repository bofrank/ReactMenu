# ReactMenu

A food ordering app built with React that allows users to browse a menu, add items to their cart, and place orders.

## Features

- Browse restaurant menu with categories
- Add/remove items to shopping cart
- Order management and tracking
- User-friendly interface

1. Clone the repository:
   ```bash
   git clone https://github.com/bofrank/ReactMenu.git
   cd ReactMenu
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```
